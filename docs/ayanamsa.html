Ayanamsa — Lahiri Correction

When calculating the positions of astronomical bodies, western astronomy uses the Tropical (Sayana) zodiac, which defines 0° Aries as the vernal equinox point in the sky. Because of the Earth's axial precession, this point slowly shifts backward through the stars at about 50.3 arc-seconds per year.

Vedic astrology (and Jamakkol Prasanam) uses the Sidereal (Nirayana) zodiac, which is tied to the actual fixed background constellations. The distance between the tropical vernal equinox and the starting point of the sidereal Aries constellation is called the Ayanamsa.

Sidereal Longitude = Tropical Longitude - Ayanamsa

The Lahiri Ayanamsa

There are several ayanamsas (different estimates of where sidereal 0° Aries is), but the official Indian government standard and the one used by all Tamil astrologers for Jamakkol is the Lahiri Ayanamsa (also called Chitra Paksha).

For reference, in the year 2026, the Lahiri Ayanamsa is approximately 24.23°. This means every tropical planet position is shifted backward by about 24 degrees to get its sidereal position!

Setting Ayanamsa in pysweph

You must tell the Swiss Ephemeris library to use the Lahiri ayanamsa before performing any planet calculations. Use the swe.set_sid_mode() function:

swe.set_sid_mode(sid_mode, t0, ayan_t0) → Returns: None
sid_mode : int
The sidereal mode constant. For Lahiri, use swe.SIDM_LAHIRI.
t0 : float = 0
Reference epoch (0 for standard mode).
ayan_t0 : float = 0
Initial ayanamsa value (0 for standard mode).
import pysweph as swe

# Initialize Sidereal mode with Lahiri ayanamsa
swe.set_sid_mode(swe.SIDM_LAHIRI, 0, 0)

Fetching the Current Ayanamsa Value

To inspect the exact Ayanamsa offset value for a specific Julian Day, use swe.get_ayanamsa_ut():

swe.get_ayanamsa_ut(jd) → Returns: float (Ayanamsa value in decimal degrees) 
# Calculate Ayanamsa for August 4, 2026
jd = swe.julday(2026, 8, 4, 9.0, swe.GREG_CAL)
aya = swe.get_ayanamsa_ut(jd)
print(f"Lahiri Ayanamsa: {aya:.4f}°")
# Output: Lahiri Ayanamsa: 24.2381°

⚠️ Manually Subtract for Houses / Ascendant

When calling swe.calc_ut() for planet positions, passing the swe.FLG_SIDEREAL flag automatically applies the Lahiri Ayanamsa to the result.

However, swe.houses() does not take calculation flags and always returns tropical values. To get the sidereal Ascendant or house cusps, you must manually subtract the ayanamsa: 

sidereal_asc = (tropical_asc - ayanamsa) % 360

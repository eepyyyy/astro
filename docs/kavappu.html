Kavappu (கவப்பு) — The Shadow Point

Kavappu (also written Kavippu) means "closure" or "covering" in Tamil. It represents a hidden blockage or shadow influence in the chart — a Rasi that is under some kind of pressure or obstruction. The planet ruling the Kavappu Rasi and any planets placed there can delay or prevent the desired outcome.

How it's calculated

Calculating Kavappu requires four main inputs:

  • The Udhayam Rasi (see Udhayam)
  • The Arudham Rasi (see Arudham)
  • The Sun's current Rasi (from swe.calc_ut())
  • The Soorya Veedi Rasi (calculated from the Sun's current Rasi)
⚠️ IMPORTANT: 0-Indexed Rasi Indices
In code arrays and astronomical engines, the 12 signs are 0-indexed (0 to 11). Mesham (Aries) = 0, Thulaam (Libra) = 6, and Meenam (Pisces) = 11. Using 1-indexed values (1 to 12) will cause out-of-bounds index translation errors.

Step 1 — Find the Soorya Veedi

The Sun's path (Soorya Veedi) determines a representative Rasi based on the Sun's transit sign (using 0-indexed Rasis):

  • Mesha Veedhi (Aries): If the Sun is in Taurus (1), Gemini (2), Cancer (3), or Leo (4). Representative Rasi index = 0.
  • Vrishabha Veedhi (Taurus): If the Sun is in Aries (0), Virgo (5), Libra (6), or Pisces (11). Representative Rasi index = 1.
  • Mithuna Veedhi (Gemini): If the Sun is in Scorpio (7), Sagittarius (8), Capricorn (9), or Aquarius (10). Representative Rasi index = 2.

Step 2 — Apply the Offset

Instead of counting with inclusive offsets (adding 1 for inclusive distance and subtracting 1 to project from Udhayam, which mathematically cancel out), we use a direct relative distance offset:

Kavappu Formula
kavappu_rasi = (udhayam_rasi + veedi_rasi - arudham_rasi) % 12

Step 3 — Degree & Retrograde Status

Kavappu moves in the opposite direction (retrograde) to Arudham. As Arudham progresses forward from 0° to 30°, Kavappu moves backward from 30° to 0° (with a 1" offset to match jamakkol.com).

Kavappu Degree Formula
kavappu_deg_in_rasi = 30.0 - arudham_deg_in_rasi - (1.0 / 3600.0)
kavappu_deg = kavappu_rasi * 30.0 + kavappu_deg_in_rasi

A Worked Example

Suppose (at 10:24:10 PM):

  • Sun is in Cancer (Rasi index 3) → Soorya Veedi is Mesha (Rasi index 0)
  • Arudham is in Leo (Rasi index 4, at 25° 0' 0")
  • Udhayam is in Scorpio (Rasi index 7)

Applying the offset: kavappu_rasi = (7 + 0 - 4) % 12 = 3 = Rasi index 3 = Kadagam (Cancer).
Degree calculation: 30.0 - 25.0 - 1" = 4° 59' 59".
So Kavappu is in Kadagam (Cancer) at 4° 59' 59" (R) (absolute degree 94° 59' 59").

Code

def get_soorya_veedi(sun_rasi: int) -> int:
    """Determine the Soorya Veedi Rasi index based on the Sun's 0-indexed sign."""
    if sun_rasi in [1, 2, 3, 4]:
        return 0  # Mesha (Aries)
    elif sun_rasi in [0, 5, 6, 11]:
        return 1  # Vrishabha (Taurus)
    else:
        return 2  # Mithuna (Gemini)

def calculate_kavappu(
    udhayam_rasi: int,
    arudham_rasi: int,
    arudham_deg_in_rasi: float,
    sun_rasi:     int
) -> dict:
    """
    Calculate Kavappu (the shadow/obstacle point) using 0-indexed Rasis.
    """
    veedi_rasi = get_soorya_veedi(sun_rasi)
    kavappu_rasi = (udhayam_rasi + veedi_rasi - arudham_rasi) % 12
    
    # Retrograde complementary degree
    kavappu_deg_in_rasi = 30.0 - arudham_deg_in_rasi - (1.0 / 3600.0)
    kavappu_deg = kavappu_rasi * 30.0 + kavappu_deg_in_rasi

    return {
        "rasi"          : kavappu_rasi,
        "rasi_en"       : RASI_NAMES_EN[kavappu_rasi],
        "rasi_ta"       : RASI_NAMES_TA[kavappu_rasi],
        "degree"        : kavappu_deg,
        "is_retrograde" : True
    }

What does Kavappu tell you?

Think of the Kavappu Rasi as a "covered" or "blocked" house. Malefic planets (Saturn, Mars, Rahu, Ketu) placed in the Kavappu Rasi tend to show obstacles. The Kavappu Rasi's lord, and where that lord is placed in the chart, can show whether the blockage is temporary or severe.

In prediction: if the Kavappu falls in the same house as the querent's desired matter (e.g., 7th house for marriage, 11th for gains), it signals difficulty or delay in that area.

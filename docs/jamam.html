Jamam & Jamam Planets

In Jamakkol Prasanam, time and space are split into dynamic, symbolic sections. A Jamam (ஜாமம்) represents a division of time, while Jamam Planets (ஜாமக்கோள் கிரகங்கள்) represent symbolic planets placed on the zodiac wheel.

1. What is a Jamam?

The day is divided into two major spans: Daytime (sunrise to sunset) and Nighttime (sunset to the next sunrise). Each of these spans is divided into 8 equal parts called Jamams.

If a day has exactly 12 hours of sunlight, each daytime Jamam is exactly 1.5 hours (90 minutes). However, because day lengths change throughout the year, Jamam lengths are dynamic.

2. The Jamam Planets

In Jamakkol, there are 8 Jamam planets. The Moon is excluded from this list, and Rahu and Ketu are included. The order is fixed:

Sun → Mars → Jupiter → Mercury → Venus → Saturn → Rahu → Ketu

3. Finding the Active Jamam Lord

The ruling planet of the first Jamam depends on the weekday. Sunday starts with the Sun, Tuesday with Mars, and so on. Because the Moon is excluded, **Monday starts with Venus**.

WeekdayStart Planet (1st Jamam Lord)
SundaySun
MondayVenus
TuesdayMars
WednesdayMercury
ThursdayJupiter
FridayVenus
SaturdaySaturn

To find the lord of the active Jamam, we look up the starting planet for the weekday and step forward through the sequence. For example, on a Sunday:

  • 1st Jamam Lord: Sun
  • 2nd Jamam Lord: Mars
  • 3rd Jamam Lord: Jupiter
  • ... and so on.

4. Placing Jamam Planets on the Chart

Jamam planets do not have physical degrees; they occupy entire Rasis. Their placement is symbolic:

  • The Sun is placed in the Rasi it physically occupies at the query moment.
  • The remaining 7 planets are placed in consecutive Rasis going **clockwise** starting from the Sun's Rasi, following the fixed planet order.

Python Implementation

# Fixed planet order
JAMAM_PLANETS = ["Sun", "Mars", "Jupiter", "Mercury", "Venus", "Saturn", "Rahu", "Ketu"]

# Weekday starts (0 = Sunday ... 6 = Saturday)
DAY_START = {
    0: "Sun", 
    1: "Venus", 
    2: "Mars", 
    3: "Mercury", 
    4: "Jupiter", 
    5: "Venus", 
    6: "Saturn"
}

def get_jamam_details(jd: float, sr: float, ss: float, weekday: int, sun_rasi: int) -> dict:
    # 1. Calculate duration of a single Jamam
    jdur = (ss - sr) / 8.0
    
    # 2. Find active Jamam number (1 to 8)
    jnum = max(1, min(8, int((jd - sr) / jdur) + 1))
    
    # 3. Get active Jamam Lord
    start_p = DAY_START[weekday]
    start_idx = JAMAM_PLANETS.index(start_p)
    lord = JAMAM_PLANETS[(start_idx + jnum - 1) % 8]
    
    # 4. Map Jamam Planet Rasi placements
    jpos = {}
    for i, p in enumerate(JAMAM_PLANETS):
        jpos[p] = (sun_rasi + i) % 12  # Placed in order clockwise
        
    return {
        "active_jamam"   : jnum,
        "jamam_lord"     : lord,
        "jamam_duration" : round(jdur * 1440, 2),  # In minutes
        "placements"     : jpos
    }

Panchangam (Five Limbs of Time)

The Panchangam (பஞ்சாங்கம்) is the traditional Hindu calendar system based on the movement of the Sun and Moon. It measures five key parameters representing temporal qualities: Vaaram, Thithi, Nakshatra, Yogam, and Karanam.

1. Vaaram (Weekday)

The solar weekday. It determines the starting lord of the daytime Jamam (see Jamam).

2. Thithi (Lunar Day)

A Thithi is a lunar day representing a 12-degree elongation of the Moon relative to the Sun. There are 30 Thithis in a lunar month, split into two fortnights (Pakshas):

  • Shukla Paksha (Bright / Waxing Half): Elongation angle is between 0° and 180°.
  • Krishna Paksha (Dark / Waning Half): Elongation angle is between 180° and 360°.
diff = (Moon_longitude - Sun_longitude) % 360
thithi_number = (int(diff / 12) % 15) + 1
paksha = "Shukla" if diff < 180 else "Krishna"

3. Nakshatra (Lunar Mansion)

The stellar mansion occupied by the Moon. Calculated by dividing the Moon's longitude by 13°20' (see 27 Nakshatras).

4. Yogam (Luni-Solar Day)

Determined by summing the longitudes of the Sun and Moon. There are 27 Yogams, each spanning 13°20' (13.3333°):

sum_lon = (Sun_longitude + Moon_longitude) % 360
yogam_index = int(sum_lon / (360 / 27))

5. Karanam (Half-Thithi)

A Karanam spans exactly 6 degrees of Moon-Sun elongation (half of a Thithi). There are 60 Karanams in a lunar month, consisting of 4 fixed (immobile) Karanams and 7 recurring (mobile) Karanams:

karanam_number = int(diff / 6) + 1

Python Implementation

# Vaaram names in Tamil
VAAR_TA = ["ஞாயிறு", "திங்கள்", "செவ்வாய்", "புதன்", "வியாழன்", "வெள்ளி", "சனி"]

def calculate_panchangam(sun_lon: float, moon_lon: float, weekday: int) -> dict:
    diff = (moon_lon - sun_lon) % 360.0
    
    # 1. Thithi
    thithi_idx = int(diff // 12.0)
    thithi_num = (thithi_idx % 15) + 1
    paksha = "Shukla" if diff < 180.0 else "Krishna"
    
    # 2. Yogam (sum of positions)
    sum_lon = (sun_lon + moon_lon) % 360.0
    yogam_idx = int(sum_lon // (360.0 / 27.0))
    
    # 3. Karanam
    karanam_num = int(diff // 6.0) + 1
    
    return {
        "vaaram"      : VAAR_TA[weekday],
        "thithi"      : thithi_num,
        "paksha"      : paksha,
        "yogam_idx"   : yogam_idx,
        "karanam_num" : karanam_num,
    }

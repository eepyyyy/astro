Quick Start

Ready to calculate a chart? In this page, we'll write a simple Python script to calculate the positions of the planets and the Udhayam/Arudham using pysweph.

Your First Jamakkol Script

Create a file named quickstart.py in your project root and paste the following code: 

import pysweph as swe
from datetime import datetime, timedelta

# Initialize Swiss Ephemeris and set Sidereal Lahiri Mode
swe.set_ephe_path("")
swe.set_sid_mode(swe.SIDM_LAHIRI, 0, 0)

# 1. Define local date & time (e.g., Chennai, India)
dt_local = datetime(2026, 8, 4, 14, 30, 0)  # August 4, 2026 at 2:30 PM
tz_offset = 5.5                             # UTC+5:30 (IST)

# 2. Convert to Julian Day (using UTC time)
dt_utc = dt_local - timedelta(hours=tz_offset)
decimal_hour = dt_utc.hour + dt_utc.minute / 60.0 + dt_utc.second / 3600.0
jd = swe.julday(dt_utc.year, dt_utc.month, dt_utc.day, decimal_hour, swe.GREG_CAL)

# 3. Calculate Sun's sidereal position
flags = swe.FLG_SWIEPH | swe.FLG_SIDEREAL
res, _ = swe.calc_ut(jd, swe.SUN, flags)
sun_lon = res[0]
sun_rasi = int(sun_lon // 30)

# 4. Calculate Udhayam (rising sign for Jamakkol)
# For the sake of this quickstart, assume sunrise is at 06:00:00 IST (2461259.5208)
jd_sunrise = swe.julday(2026, 8, 4, 0.5, swe.GREG_CAL)  # 00:30 UTC = 06:00 IST
jd_sunset  = swe.julday(2026, 8, 4, 13.0, swe.GREG_CAL) # 13:00 UTC = 18:30 IST

fraction = (jd - jd_sunrise) / (jd_sunset - jd_sunrise)
udhayam_deg = (sun_rasi * 30 + fraction * 360) % 360
udhayam_rasi = int(udhayam_deg // 30)

# 5. Calculate Arudham (5-minute rule based on query local time)
total_seconds = dt_local.minute * 60 + dt_local.second
arudham_rasi = total_seconds // 300  # 5 minutes = 300 seconds per Rasi

# Rasi name lookup list
rasi_names = ["Mesham", "Rishabham", "Mithunam", "Kadagam", 
              "Simmam", "Kanni", "Thulaam", "Viruchigam", 
              "Dhanusu", "Magaram", "Kumbam", "Meenam"]

print(f"Query Time : {dt_local}")
print(f"Sun Rasi   : {rasi_names[sun_rasi]} ({sun_lon:.4f}°)")
print(f"Udhayam    : {rasi_names[udhayam_rasi]} ({udhayam_deg:.4f}°)")
print(f"Arudham    : {rasi_names[arudham_rasi]}")

Run the Code

Execute the script in your terminal using uv run (or standard python): 

uv run quickstart.py

You should see output similar to this: 

Query Time : 2026-08-04 14:30:00
Sun Rasi   : Kadagam (108.0673°)
Udhayam    : Viruchigam (229.8673°)
Arudham    : Viruchigam

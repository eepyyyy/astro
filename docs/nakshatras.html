27 Nakshatras (Lunar Mansions)

In Vedic astrology, the ecliptic is divided into 27 equal parts called Nakshatras (நட்சத்திரங்கள்). Each Nakshatra spans exactly 13°20' (13.3333 degrees). The Moon's position in a Nakshatra determines the active stellar influence at the query moment.

Nakshatra Padas

Each Nakshatra is divided into 4 quarters called Padas (பாதங்கள்). Each Pada spans exactly 3°20' (3.3333 degrees). There are a total of 108 Padas in the entire 360° zodiac (27 Nakshatras × 4 Padas = 108 Padas).

Calculating Nakshatra & Pada in Python

# The 27 Nakshatras list
NAKSHATRAS = [
    "Ashwini", "Bharani", "Krittika", "Rohini", "Mrigashira",
    "Ardra", "Punarvasu", "Pushya", "Ashlesha", "Magha",
    "Purva Phalguni", "Uttara Phalguni", "Hasta", "Chitra",
    "Svati", "Vishakha", "Anuradha", "Jyeshtha", "Mula",
    "Purva Ashadha", "Uttara Ashadha", "Shravana",
    "Dhanishtha", "Shatabhisha", "Purva Bhadrapada",
    "Uttara Bhadrapada", "Revati",
]

def get_nakshatra_info(deg: float) -> dict:
    deg = deg % 360.0
    
    # 360 / 27 = 13.3333 degrees per Nakshatra
    ni = int(deg // (360.0 / 27.0))
    
    # 360 / 108 = 3.3333 degrees per Pada (4 Padas per Nakshatra)
    pada = int((deg % (360.0 / 27.0)) // (360.0 / 108.0)) + 1
    
    return {
        "index": ni,
        "name": NAKSHATRAS[ni],
        "pada": pada,
    }

# Example: Moon is at 235.12°
info = get_nakshatra_info(235.12)
print(f"Moon is in Nakshatra: {info['name']}, Pada: {info['pada']}")
# Output: Moon is in Nakshatra: Jyeshtha, Pada: 2

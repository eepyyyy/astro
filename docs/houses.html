Ascendant — swe.houses()

The Ascendant (Lagna) represents the intersection of the eastern horizon with the ecliptic at any given moment. In traditional Vedic and Western astrology, it is the starting point of the 1st house.

In Jamakkol Prasanam, the rising sign of the query itself is called Udhayam. However, Udhayam is computed by a symbolic progression of the Sun throughout the day (see Udhayam). Standard physical Ascendant calculations are still critical because the sub-planets Mandi and Gulika are calculated by finding the physical Ascendant at their specific planetary hour times (see Mandi & Gulika).

The Function

To compute house cusps and the Ascendant, use the swe.houses() function:

swe.houses(jd, lat, lon, hsys) → Returns: (cusps, ascmc)

Parameters

jd : float
Julian Day number (must be in Universal Time UTC).
lat : float
Latitude of the observer in degrees (positive = North, negative = South).
lon : float
Longitude of the observer in degrees (positive = East, negative = West).
hsys : bytes
A single-character byte string representing the house system:
  • b'P': Placidus (most common in modern astrology)
  • b'O': Porphyry
  • b'E': Equal HouseDetails
  • b'W': Whole Sign

Return Values

The function returns a tuple of two lists:

  • cusps: A list of 13 floats. Index 0 is unused. Indexes 1 through 12 represent the starting longitude of the 1st through 12th houses.
  • ascmc: A list of 10 floats containing secondary calculations:
    • ascmc[0]: The Ascendant (Lagna) longitude
    • ascmc[1]: The Midheaven (MC) longitude
    • ascmc[2]: Vertex
    • ascmc[3]: East Point

Calculating Sidereal Ascendant

📌 Important Ayanamsa Correction

Unlike planetary positions, swe.houses() does not apply the sidereal ayanamsa automatically. It always returns tropical values.

To get the sidereal Ascendant, you must manually fetch the ayanamsa value at that Julian Day and subtract it: 

import pysweph as swe

# Define coordinates (e.g., Chennai, India: 13.0827° N, 80.2707° E)
lat = 13.0827
lon = 80.2707
jd = swe.julday(2026, 8, 4, 9.0, swe.GREG_CAL)  # Aug 4, 2026 14:30 IST

# 1. Fetch the tropical house calculations
cusps, ascmc = swe.houses(jd, lat, lon, b'P')
tropical_asc = ascmc[0]

# 2. Get the Lahiri Ayanamsa
swe.set_sid_mode(swe.SIDM_LAHIRI, 0, 0)
ayanamsa = swe.get_ayanamsa_ut(jd)

# 3. Calculate sidereal Ascendant
sidereal_asc = (tropical_asc - ayanamsa) % 360

print(f"Tropical Ascendant: {tropical_asc:.4f}°")
print(f"Sidereal Ascendant: {sidereal_asc:.4f}°")
# Output: 
# Tropical Ascendant: 254.1054° (Dhanusu / Sagittarius)
# Sidereal Ascendant: 229.8673° (Viruchigam / Scorpio)

12 Rasis (Signs of the Zodiac)

The zodiac belt of 360 degrees is divided into 12 equal sectors of 30 degrees each, called Rasis (இராசிகள்). In Jamakkol Prasanam, these represent the physical houses of the chart where planets are positioned.

The 12 Rasis Table

Index (0-11) Tamil Name English / Sanskrit Name Zodiac Span Ruling Planet (Lord)
0மேஷம் (Mesham)Aries0° – 30°Mars
1ரிஷபம் (Rishabham)Taurus30° – 60°Venus
2மிதுனம் (Mithunam)Gemini60° – 90°Mercury
3கடகம் (Kadagam)Cancer90° – 120°Moon
4சிம்மம் (Simmam)Leo120° – 150°Sun
5கன்னி (Kanni)Virgo150° – 180°Mercury
6துலாம் (Thulaam)Libra180° – 210°Venus
7விருச்சிகம் (Viruchigam)Scorpio210° – 240°Mars
8தனுசு (Dhanusu)Sagittarius240° – 270°Jupiter
9மகரம் (Magaram)Capricorn270° – 300°Saturn
10கும்பம் (Kumbam)Aquarius300° – 330°Saturn
11மீனம் (Meenam)Pisces330° – 360°Jupiter

Longitude to Rasi Conversion

To convert any planet's longitude (0.0 to 360.0 degrees) to its Rasi index, use integer division by 30:

rasi_index = int(longitude // 30)
degree_in_rasi = longitude % 30

Python Code Example

# Rasi names arrays
RASI_TA = ["மேஷம்", "ரிஷபம்", "மிதுனம்", "கடகம்", "சிம்மம்", "கன்னி",
           "துலாம்", "விருச்சிகம்", "தனுசு", "மகரம்", "கும்பம்", "மீனம்"]

RASI_EN = ["Mesham", "Rishabham", "Mithunam", "Kadagam", "Simmam", "Kanni",
           "Thulaam", "Viruchigam", "Dhanusu", "Magaram", "Kumbam", "Meenam"]

def get_rasi_info(deg: float) -> dict:
    deg = deg % 360.0
    ri = int(deg // 30)
    deg_in_rasi = deg % 30
    return {
        "index": ri,
        "name_ta": RASI_TA[ri],
        "name_en": RASI_EN[ri],
        "deg_in_rasi": round(deg_in_rasi, 4),
    }

# Example: Sun is at 108.0673°
info = get_rasi_info(108.0673)
print(f"Sun is in {info['name_en']} ({info['name_ta']}) at {info['deg_in_rasi']}°")
# Output: Sun is in Kadagam (கடகம்) at 18.0673°

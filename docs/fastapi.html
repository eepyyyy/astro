FastAPI Server

Now that you have the calculation engine, wrapping it in a REST API takes about 30 lines. FastAPI is perfect for this — it auto-generates documentation at /docs, validates input types automatically, and handles errors cleanly.

The main.py file

"""
main.py — Jamakkol Prasanam REST API

Run with:   uv run uvicorn main:app --reload
Open docs:  http://localhost:8000/docs
"""
from fastapi import FastAPI, HTTPException, Query
from datetime import datetime
from jamakkol_engine import compute

app = FastAPI(
    title       = "Jamakkol Prasanam API",
    description = "High-accuracy Jamakkol Prasanam via Swiss Ephemeris.",
    version     = "1.0.0",
)


@app.get("/")
def root():
    return {"status": "online", "docs": "/docs"}


@app.get("/api/v1/prasanam")
def prasanam(
    date : str   = Query(..., example="2026-08-04",
                        description="Date YYYY-MM-DD"),
    time : str   = Query(..., example="14:30:00",
                        description="Local time HH:MM:SS"),
    lat  : float = Query(..., example=13.0827,
                        description="Astrologer's latitude"),
    lon  : float = Query(..., example=80.2707,
                        description="Astrologer's longitude"),
    tz   : float = Query(5.5,
                        description="Timezone offset in hours (IST = 5.5)"),
    alt  : float = Query(0.0,
                        description="Elevation in metres (optional)"),
):
    """
    Get a complete Jamakkol Prasanam chart for a given time and place.

    Pass the ASTROLOGER's location — not the client's. In Jamakkol,
    the chart is cast for where the question was asked.
    """
    try:
        dt     = datetime.strptime(f"{date} {time}", "%Y-%m-%d %H:%M:%S")
        result = compute(dt, lat, lon, tz, alt)
        return {"status": "ok", "data": result}
    except ValueError as e:
        raise HTTPException(status_code=422, detail=f"Invalid date/time: {e}")
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

Running the Server

uv run uvicorn main:app --reload --port 8000

Once it's running, open http://localhost:8000/docs — FastAPI auto-generates an interactive UI where you can test every endpoint.

Testing with curl

curl "http://localhost:8000/api/v1/prasanam?date=2026-08-04&time=14:30:00&lat=13.0827&lon=80.2707"

Why the astrologer's location?

In Jamakkol Prasanam, the chart is drawn for where the question is asked — not where the person asking lives. If someone calls you from Mumbai but you're in Chennai, you use Chennai's coordinates. This is because the sunrise time (which determines the Jamam and Udhayam) is calculated for your local sky.

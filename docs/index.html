Jamakkol Prasanam — Developer Documentation

import pysweph as swe
from jamakkol_engine import compute
from datetime import datetime

result = compute(
    dt_local=datetime(2026, 8, 4, 14, 30, 0),
    lat=13.0827,  # Chennai
    lon=80.2707,
)
print(result["udhayam"]["rasi_ta"])   # → விருச்சிகம்
print(result["arudham"]["rasi_ta"])   # → கடகம்

What is this?

Jamakkol Prasanam (ஜாமக்கோள் பிரசன்னம்) is a Tamil horary astrology system — you ask it a question at a specific moment, and it gives you an answer by reading the "sky map" at that exact second. Think of it like a snapshot of the planets, but instead of a birth chart, it's a question chart.

This library (pysweph) gives you access to NASA-level planet calculations in Python. We use it to build all the pieces of a Jamakkol chart: the rising sign (Udhayam), the answer point (Arudham), the obstacle point (Kavappu), and the positions of all 9 planets.

How do I use these docs?

If you're completely new, follow the sidebar top to bottom — it's designed in that order. If you already know astrology and just need the code, use the Building the API section on the left.

Each page explains why something works the way it does, not just how to call a function. You should be able to understand and reproduce every calculation without copying code blindly.

📌 Note

All calculations in this guide use the Lahiri Ayanamsa — the standard correction used by all Tamil and South Indian astrologers. This is already set up in the engine code.

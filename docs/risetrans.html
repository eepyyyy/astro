Sunrise & Sunset — swe.rise_trans()

In Jamakkol Prasanam, the astronomical day is divided into two parts: Daytime (from sunrise to sunset) and Nighttime (from sunset to next sunrise). Knowing the exact sunrise and sunset times is critical for:

  • Dividing the day/night into 8 equal Jamams (approximately 90 minutes each).
  • Calculating the progression of the Udhayam (rising degree) from the Sun's position.
  • Determining Mandi and Gulika portions based on day/night lengths.

The Function

To compute when a body rises or sets, use the swe.rise_trans() function:

swe.rise_trans(jd_start, body_id, rise_set_flag, lon, lat, alt, pressure, temp) → Returns: (t_ret, serr)

Parameters

jd_start : float
Julian Day number (UT) to start searching forward from.
body_id : int
Body constant (for Sun, use swe.SUN).
rise_set_flag : int
Which event to compute:
  • swe.CALC_RISE: Sunrise (upper limb touches horizon)
  • swe.CALC_SET: Sunset
lon, lat, alt : float
Longitude (East = positive), latitude (North = positive) in degrees, and altitude in meters above sea level.
pressure, temp : float
Atmospheric pressure in hPa (use 0 for standard 1013.25) and temperature in °C (use 0 for standard 15°C). Atmospheric refraction is calculated automatically.

Determining the Active Span

Because the query can occur before today's sunrise or after today's sunset, we must check three days' worth of sunrises/sunsets: yesterday's, today's, and tomorrow's. 

def get_rise_set(jd_utc: float, lat: float, lon: float, alt: float = 0):
    # Start searching from midnight before the target date
    midnight = int(jd_utc) - 0.5
    
    # Today's rise/set
    _, sr_res = swe.rise_trans(midnight, swe.SUN, swe.CALC_RISE, [lon, lat, alt], 0, 0)
    _, ss_res = swe.rise_trans(midnight, swe.SUN, swe.CALC_SET,  [lon, lat, alt], 0, 0)
    sr, ss = sr_res[0], ss_res[0]
    
    # Yesterday's rise/set (for early morning queries)
    _, psr_res = swe.rise_trans(midnight - 1, swe.SUN, swe.CALC_RISE, [lon, lat, alt], 0, 0)
    _, pss_res = swe.rise_trans(midnight - 1, swe.SUN, swe.CALC_SET,  [lon, lat, alt], 0, 0)
    psr, pss = psr_res[0], pss_res[0]
    
    # Tomorrow's rise/set (for late night queries)
    _, nsr_res = swe.rise_trans(midnight + 1, swe.SUN, swe.CALC_RISE, [lon, lat, alt], 0, 0)
    nsr = nsr_res[0]
    
    # Determine the span
    if sr <= jd_utc < ss:
        return sr, ss, True        # Daytime (between today's sunrise and sunset)
    elif jd_utc < sr:
        return pss, sr, False      # Nighttime (between yesterday's sunset and today's sunrise)
    else:
        return ss, nsr, False      # Nighttime (between today's sunset and tomorrow's sunrise)

📌 Elevation Matters

Setting the altitude (alt) parameter correctly is important. A location at sea level vs. 500m up a mountain will see sunrise several minutes apart. Swiss Ephemeris accounts for the dip of the horizon caused by elevation.

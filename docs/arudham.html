Arudham (ஆருடம்) — The Answer Point

Arudham is the most important point in a Jamakkol Prasanam chart. It reveals the nature of the query and ultimately points toward the answer. The house lord of the Arudham's Rasi tells you what the question is really about.

The modern computational method — used by most software including jamakkol.com — is beautifully simple: it's based entirely on the minute of the hour when the question is asked. It has nothing to do with sunrise, sunset, or the Sun's position. It's just clock time.

The 5-Minute Rule

Each hour (60 minutes) is divided into 12 equal segments of 5 minutes each. Each segment corresponds to one Rasi, going from Mesham (Aries) to Meenam (Pisces). At the top of every hour, it resets to Mesham.

So if someone asks a question at 2:37 PM, the minute-of-hour is 37. That falls in the 35–39 range → Viruchigam (Scorpio) is the Arudham.

If the question is at 2:00 PM exactly, the minute is 0 → Mesham (Aries).

The Formula

Arudham — Using Seconds for Precision
total_seconds = minute × 60 + second # 0 to 3599
arudham_rasi = total_seconds // 300 # 300 seconds = 5 minutes
seconds_in_rasi = total_seconds % 300 # 0 to 299
deg_in_rasi = seconds_in_rasi × (30.0 / 300) # maps seconds to 0°–30°
arudham_degree = arudham_rasi × 30 + deg_in_rasi

Code

from datetime import datetime

def calculate_arudham(dt_local: datetime) -> dict:
    """
    Calculate Arudham based on the local time of the query.

    Uses the 5-minute rule: each 5 minutes of the hour = 1 Rasi.
    Works purely from the clock — no sunrise or Sun position needed.
    """
    # Total seconds elapsed since the top of the current hour
    total_seconds = dt_local.minute * 60 + dt_local.second

    # Each 300 seconds (5 minutes) = one Rasi (0 to 11)
    arudham_rasi    = total_seconds // 300
    seconds_in_rasi = total_seconds % 300

    # Map seconds within this 5-min block to a degree (0–30°)
    # 300 seconds → 30 degrees, so 1 second = 0.1 degree
    deg_in_rasi    = seconds_in_rasi * (30.0 / 300.0)
    arudham_degree = (arudham_rasi * 30.0 + deg_in_rasi) % 360.0

    return degree_to_rasi_info(arudham_degree)


# Example usage
dt = datetime(2026, 8, 4, 14, 37, 30)  # 2:37:30 PM local
arudham = calculate_arudham(dt)
print(arudham["rasi_ta"])  # → விருச்சிகம் (Scorpio)

💡 Why use seconds?

If you only use minutes (not seconds), the Arudham degree within the Rasi is always a round number. Using seconds gives you a more precise degree like 13.5° instead of just "Viruchigam". This matters for exact degree-level analysis and matches the output of jamakkol.com more closely.

This has nothing to do with location

Unlike Udhayam (which depends on sunrise at the astrologer's location) and Mandi (which requires knowing the exact daylight duration), Arudham only uses the clock time. It doesn't matter where you are in the world — it's the same Arudham in Chennai and in London at the same local minute.

How to use it in prediction

The Arudham Rasi, its lord planet, and any Jamam planets in the Arudham Rasi describe the nature of the question and the main influence on the outcome. If the Arudham lord and the Udhayam lord are the same, or placed beneficially relative to each other, the prognosis tends to be favourable.

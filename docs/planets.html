Nitya Grahas (9 Planets)

In Jamakkol Prasanam, the physical astronomical bodies in the sky are referred to as the Nitya Grahas (நித்திய கிரகங்கள்) or "constant planets". These represent the actual physical energies influencing the chart at the query moment.

There are 9 Nitya Grahas: the Sun, Moon, Mars, Mercury, Jupiter, Venus, Saturn, and the two lunar nodes, Rahu and Ketu.

2. Calculation Methodology

To compute a planet's sidereal coordinates, we call swe.calc_ut() with flags indicating we want sidereal positions and speed (to check for retrograde motion). 

import pysweph as swe

# Set up Lahiri Ayanamsa
swe.set_ephe_path("")
swe.set_sid_mode(swe.SIDM_LAHIRI, 0, 0)

# Use Swiss Ephemeris, Sidereal Zodiac, and Speed flags
flags = swe.FLG_SWIEPH | swe.FLG_SIDEREAL | swe.FLG_SPEED

jd = swe.julday(2026, 8, 4, 9.0, swe.GREG_CAL)  # August 4, 2026 14:30 IST

# Compute Jupiter's position
res, _ = swe.calc_ut(jd, swe.JUPITER, flags)
lon = res[0]
speed = res[3]

print(f"Jupiter Sidereal Longitude: {lon:.4f}°")
print(f"Jupiter Speed in Longitude: {speed:.6f}°/day")

3. Retrograde Motion (℞)

When a planet's speed in longitude (res[3]) is negative, it is moving backward relative to the stars. This is called retrograde motion.

  • In astrological interpretations, retrograde planets represent intensified, internal, or delayed results.
  • Rahu and Ketu are node points and are always retrograde in their normal movement.
  • The Sun and Moon can never be retrograde.

4. Calculating Ketu

Swiss Ephemeris calculates Rahu (the North Node) directly. The South Node, Ketu, is always exactly opposite Rahu in the sky (180 degrees away).

Ketu Longitude = (Rahu Longitude + 180°) % 360

📌 Node Types

Vedic astrologers prefer the **True Node** (swe.TRUE_NODE) because it represents the actual instantaneous intersection point of the orbits. Some systems use the **Mean Node** (swe.MEAN_NODE), which averages out short-term orbital wobbles.

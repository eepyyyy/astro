Udhayam (உதயம்) — The Rising Sign

Udhayam is the first thing you calculate in a Jamakkol chart. It's the "ascendant" of the Prasanam — the rising sign at the moment of the query. But here's what makes it different from a regular birth chart ascendant:

In a normal birth chart, the ascendant moves through all 12 Rasis in one full day (~24 hours). So each Rasi holds the ascendant for about 2 hours.

In Jamakkol, the Udhayam completes a full 12-Rasi cycle between sunrise and sunset (one day cycle), then another full cycle from sunset to sunrise (one night cycle). If the day is 12 hours long, each Rasi gets 1 hour. If it's a short winter day (10 hours), each Rasi gets only 50 minutes.

📌 Key rule

At sunrise, the Udhayam begins at the start of the Sun's current Rasi (not the Sun's exact degree). For example, if the Sun is at 18° of Kadagam, the Udhayam starts at 0° of Kadagam at sunrise.

Why does it work this way?

In Jamakkol tradition, the Sun is the master of the day. The day "belongs" to the Sun, so the rising sign starts from the Sun's Rasi. The Udhayam then marches through all 12 signs in proportion to the day's length — giving each moment its own unique rising sign.

The Algorithm — Step by Step

  • 1
    Get the query's Julian Day

    Convert the query's local time to UTC, then to a Julian Day number using swe.julday().

  • 2
    Get today's sunrise and sunset Julian Days

    Use swe.rise_trans() with the astrologer's location. You'll also need yesterday's sunset and tomorrow's sunrise for night queries.

  • 3
    Find the current span (Day or Night)

    If sunrise ≤ query < sunset, it's a Day span. If the query is before today's sunrise, the span is yesterday's sunset → today's sunrise. If after today's sunset, the span is today's sunset → tomorrow's sunrise.

  • 4
    Calculate what fraction of the span has elapsed

    fraction = (query_jd - span_start_jd) / (span_end_jd - span_start_jd)

  • 5
    Map the fraction to a degree in the zodiac

    Start from the beginning of the Sun's Rasi (sun_rasi_index × 30°), then add fraction × 360°. Take modulo 360 to stay within bounds.

The Formula

Udhayam Degree
span_start = jd_sunrise (or prev_sunset for night query before sunrise)
span_end = jd_sunset (or next_sunrise for night query)

fraction = (jd_query - span_start) / (span_end - span_start)
udhayam_degree = (sun_rasi_index × 30 + fraction × 360) % 360

Code

def calculate_udhayam(
    jd_query,
    jd_sunrise, jd_sunset,
    jd_prev_sunset, jd_next_sunrise,
    sun_rasi_index: int
) -> dict:
    """
    Calculate the Jamakkol Udhayam (rising sign) for a query moment.

    sun_rasi_index: 0 = Mesham, 1 = Rishabham ... 11 = Meenam
                    Get this from the Sun's sidereal longitude // 30
    """
    # Which span are we in?
    if jd_sunrise <= jd_query < jd_sunset:
        span_start, span_end = jd_sunrise, jd_sunset       # Day query
    elif jd_query < jd_sunrise:
        span_start, span_end = jd_prev_sunset, jd_sunrise  # Last night query
    else:
        span_start, span_end = jd_sunset, jd_next_sunrise  # Tonight query

    # Fraction of the day/night that has passed
    fraction = (jd_query - span_start) / (span_end - span_start)

    # Udhayam starts at the beginning of the Sun's Rasi
    # E.g. if Sun is at 18° Kadagam, start = 3 × 30 = 90°
    start_deg     = sun_rasi_index * 30.0
    udhayam_deg   = (start_deg + fraction * 360.0) % 360.0

    return degree_to_rasi_info(udhayam_deg)   # see engine page

Common Mistakes

⚠️ Don't use the astronomical Ascendant for Udhayam

The swe.houses() function gives you the standard astronomical ascendant. Do not use this as the Udhayam in Jamakkol. They are entirely different things. The astronomical ascendant uses Earth's rotation; the Udhayam uses the Sun's Rasi and daylight duration.

⚠️ Start from the Rasi boundary, not the Sun's degree

If the Sun is at 18° Kadagam, you do NOT start from 18°. You start from 0° Kadagam (= 90°). The Sun's Rasi sets the starting Rasi, but the Udhayam always starts from the beginning of that Rasi.

Interpreting Udhayam

The Udhayam Rasi and its lord (the planet that rules that Rasi) form the foundation of the interpretation. Planets placed in or aspecting the Udhayam, planets that have already crossed the Udhayam, and planets approaching it tell you about the past, present, and future of the querent's situation.

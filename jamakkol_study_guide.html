What is PySweph & Swiss Ephemeris?

The astronomical engine behind the API

PySweph is a Python wrapper for the Swiss Ephemeris — the most accurate, open-source planetary calculation library in the world, used by NASA and professional astrology software. It provides planetary positions accurate to the arc-second level.

🔭 Swiss Ephemeris

Based on NASA JPL DE431 planetary tables. Covers dates from 5401 BC to 5399 AD. Accuracy: < 1 arc-second.

🐍 PySweph

Community-maintained Python C-binding fork of pyswisseph. Works on Python 3.10+. Install via: pip install pysweph

Ephemeris Data Files (Important!)

⚠️ Built-in Moshier vs Full JPL Ephemeris

Moshier (Built-in): No extra files needed. Accuracy: ±1 arc-second for 3000 BC – 3000 AD. Sufficient for Jamakkol.

Full JPL DE431: Download .se1 files from astro.com/swisseph. Accuracy: <1 arc-second for 13,000 years. Set path: swe.set_ephe_path("/path/to/ephe")

Python — Setup Template
import pysweph as swe

# Option 1: Use built-in Moshier ephemeris (no files needed)

# Option 2: Use full JPL ephemeris files (higher precision)
swe.set_ephe_path(r"C:\path\to\ephe")

# CRITICAL: Set Lahiri Ayanamsa for Tamil/Indian astrology
swe.set_sid_mode(swe.SIDM_LAHIRI, 0, 0)

Core PySweph API — All Key Functions

Every function you need, with full parameter explanations

3.1 — swe.julday() — Convert Date to Julian Day

The Julian Day Number (JD) is the universal time format used by all Swiss Ephemeris functions. Every single calculation starts here.

Python
swe.julday(year, month, day, hour_decimal, calendar)

# Parameters:
#   year         : int  — e.g. 2026
#   month        : int  — 1 to 12
#   day          : int  — 1 to 31
#   hour_decimal : float — UTC hour + minutes/60 + seconds/3600
#                  e.g. 14h 30m 00s UTC = 14.5
#   calendar     : swe.GREG_CAL (Gregorian) or swe.JUL_CAL (Julian)

# RETURNS: float (Julian Day Number)

# ── Example ──────────────────────────────────────────────────
from datetime import datetime, timedelta

def get_julian_day(dt_utc: datetime) -> float:
    """Convert UTC datetime to Julian Day Number."""
    decimal_hour = (
        dt_utc.hour
        + dt_utc.minute / 60.0
        + dt_utc.second / 3600.0
        + dt_utc.microsecond / 3_600_000_000.0
    )
    return swe.julday(
        dt_utc.year, dt_utc.month, dt_utc.day,
        decimal_hour, swe.GREG_CAL
    )

# IST is UTC+5:30, so subtract 5.5 hours
dt_ist = datetime(2026, 8, 4, 14, 30, 0)
dt_utc = dt_ist - timedelta(hours=5.5)
jd = get_julian_day(dt_utc)
# jd ≈ 2461259.291667

3.2 — swe.calc_ut() — Planetary Positions

This is the most important function. It returns a planet's longitude, latitude, distance, and speed at a given Julian Day.

Python
swe.calc_ut(jd_ut, planet_id, flags)

# Returns: (result_tuple, return_flag)
# result_tuple[0] = Ecliptic longitude (0–360°)
# result_tuple[1] = Ecliptic latitude  (-90 to +90°)
# result_tuple[2] = Distance from Earth (AU)
# result_tuple[3] = Daily speed in longitude (°/day)
# result_tuple[4] = Daily speed in latitude
# result_tuple[5] = Daily speed in distance
# Negative speed → Planet is RETROGRADE (வக்கிரம்)

# ── Planet Constants ────────────────────────────────────────
# swe.SUN       = 0     ☉ Suryan
# swe.MOON      = 1     ☽ Chandran
# swe.MERCURY   = 2     ☿ Budhan
# swe.VENUS     = 3     ♀ Sukran
# swe.MARS      = 4     ♂ Sevvai
# swe.JUPITER   = 5     ♃ Guru
# swe.SATURN    = 6     ♄ Sani
# swe.TRUE_NODE = 11    ☊ Rahu (North Node — True)
# swe.MEAN_NODE = 10    ☊ Rahu (Mean Node)
# Ketu = Rahu longitude + 180° (always opposite)

# ── Flags ──────────────────────────────────────────────────
# swe.FLG_SWIEPH   = Use Swiss Ephemeris files
# swe.FLG_MOSEPH   = Use built-in Moshier (no files needed)
# swe.FLG_SIDEREAL = Return sidereal longitude (subtracts ayanamsa)
# swe.FLG_SPEED    = Include daily speed in result
# Combine with |: swe.FLG_SWIEPH | swe.FLG_SIDEREAL | swe.FLG_SPEED

# ── Example: Get all planets ────────────────────────────────
flags = swe.FLG_SWIEPH | swe.FLG_SIDEREAL | swe.FLG_SPEED

for name, pid in [
    ("Sun", swe.SUN), ("Moon", swe.MOON), ("Mars", swe.MARS),
    ("Mercury", swe.MERCURY), ("Jupiter", swe.JUPITER),
    ("Venus", swe.VENUS), ("Saturn", swe.SATURN),
    ("Rahu", swe.TRUE_NODE),
]:
    res, _ = swe.calc_ut(jd, pid, flags)
    lon      = res[0]          # Sidereal longitude
    speed    = res[3]          # Daily motion
    retro    = speed < 0       # Retrograde check
    rasi_idx = int(lon // 30)  # 0=Aries...11=Pisces
    print(f"{name}: {lon:.4f}° | Rasi {rasi_idx+1} | Retro={retro}")

3.4 — swe.houses() — Ascendant & HouseDetails Cusps

Python
swe.houses(jd_ut, lat, lon, hsys)
# hsys (house system as bytes):
#   b'P' = Placidus         b'E' = Equal (Sign-based)
#   b'K' = Koch             b'W' = Whole Sign
# Use b'E' for Jamakkol (sign-equal houses)

# Returns: (cusps_tuple, ascmc_tuple)
# cusps_tuple  = 13 values, cusps[1]..cusps[12] are house cusps
# ascmc_tuple:
#   [0] = Ascendant (tropical longitude)
#   [1] = MC (Midheaven)
#   [2] = ARMC
#   [3] = Vertex

# ── Example: Get sidereal Ascendant (Udhayam base) ─────────
cusps, ascmc = swe.houses(jd, lat=13.0827, lon=80.2707, hsys=b'P')
tropical_asc  = ascmc[0]
ayanamsa      = swe.get_ayanamsa_ut(jd)
sidereal_asc  = (tropical_asc - ayanamsa) % 360.0
udhayam_rasi  = int(sidereal_asc // 30)  # 0=Mesha...11=Meena

3.5 — swe.rise_trans() — Sunrise & Sunset

Python
swe.rise_trans(jd_ut, body, rsmi, geolon, geolat, geoalt, atpress, attemp)

# Parameters:
#   jd_ut   : Julian Day (UT) — start search from this point
#   body    : swe.SUN for sunrise/sunset
#   rsmi    : swe.CALC_RISE (sunrise) or swe.CALC_SET (sunset)
#             Add swe.BIT_DISC_CENTER for solar disc center
#   geolon  : Longitude in degrees (positive=East, negative=West)
#   geolat  : Latitude in degrees (positive=North, negative=South)
#   geoalt  : Altitude above sea level in meters
#   atpress : Atmospheric pressure (hPa). 0 = standard (1013.25)
#   attemp  : Air temperature (°C). 0 = standard (15°C)

# Returns: (result_list, return_flag)
# result_list[0] = Julian Day of the event (in UT)

# ── Example: Chennai Sunrise ────────────────────────────────
LAT, LON, ALT = 13.0827, 80.2707, 6  # Chennai, 6m elevation

# Search for sunrise: start from midnight UTC of query date
from datetime import datetime
dt       = datetime(2026, 8, 4)        # midnight local
jd_start = get_julian_day(dt)         # anchor point

res_rise, _ = swe.rise_trans(
    jd_start, swe.SUN, swe.CALC_RISE,
    LON, LAT, ALT, 0, 0
)
res_set, _ = swe.rise_trans(
    jd_start, swe.SUN, swe.CALC_SET,
    LON, LAT, ALT, 0, 0
)

jd_sunrise = res_rise[0]   # Julian Day of sunrise (UT)
jd_sunset  = res_set[0]    # Julian Day of sunset  (UT)

# Convert JD back to datetime:
def jd_to_datetime(jd):
    y, m, d, h = swe.revjul(jd, swe.GREG_CAL)
    hour    = int(h)
    minutes = int((h - hour) * 60)
    seconds = int(((h - hour) * 60 - minutes) * 60)
    return datetime(int(y), int(m), int(d), hour, minutes, seconds)

Udhayam (உதயம்) — Rising Sign

The focal point of the Prasanam chart
📖 What is Udhayam?

Udhayam is the special Jamakkol Ascendant — not the standard astronomical Lagna. It completes a full 12-rasi cycle from Sunrise to Sunset (Day Cycle), and another full cycle from Sunset to next Sunrise (Night Cycle). At Sunrise, it starts at the Sun's current Rasi.

Udhayam Calculation Algorithm

1
Get Sunrise and Sunset Julian Days

Use swe.rise_trans() to get precise local sunrise and sunset times as Julian Days (UT).

2
Determine Day or Night Query

If jd_sunrise ≤ jd_query < jd_sunset, it's a Day query. Otherwise it's Night (use prev sunset → next sunrise).

3
Get Sun's Current Rasi

Calculate the Sun's sidereal longitude via swe.calc_ut() with FLG_SIDEREAL. Then sun_rasi = int(sun_lon // 30).

4
Calculate Time Elapsed Fraction

Fraction = (jd_query - jd_start) / (jd_end - jd_start) — where start = sunrise/prev sunset, end = sunset/next sunrise.

5
Map Fraction to Udhayam Degree

Udhayam traverses 360° in one day/night span. Degrees elapsed = fraction × 360°. Starting from Sun's Rasi start degree.

Python — Udhayam Engine
def calculate_udhayam(jd_query, jd_sunrise, jd_sunset,
                       jd_prev_sunset, jd_next_sunrise,
                       sun_rasi_index: int) -> dict:
    """
    Compute Jamakkol Udhayam for a query time.
    Udhayam traverses 12 signs in 1 day (sunrise-to-sunset)
    or 1 night (sunset-to-sunrise), starting from Sun's rasi.
    """
    is_day = jd_sunrise <= jd_query < jd_sunset

    if is_day:
        span_start = jd_sunrise
        span_end   = jd_sunset
    elif jd_query < jd_sunrise:  # Before today's sunrise (last night)
        span_start = jd_prev_sunset
        span_end   = jd_sunrise
    else:                           # After today's sunset (tonight)
        span_start = jd_sunset
        span_end   = jd_next_sunrise

    # Fraction of span elapsed at query time
    span_days    = span_end - span_start
    elapsed_days = jd_query - span_start
    fraction     = elapsed_days / span_days

    # Udhayam starts at Sun's rasi (beginning of that rasi = sun_rasi * 30)
    start_deg   = sun_rasi_index * 30.0
    udayam_deg  = (start_deg + fraction * 360.0) % 360.0

    return degree_to_rasi_info(udayam_deg)
⚠️
Key Difference from Standard Lagna The standard astronomical Ascendant (from swe.houses()) changes based on Earth's rotation (~4 minutes per degree). Jamakkol Udhayam moves proportionally based on daylight duration. They are DIFFERENT. Use the formula above for Jamakkol.

Arudham (ஆருடம்) — Query Answer Point

The decisive point indicating the answer to the query
📖 What is Arudham?

Arudham indicates the subject and nature of the query — and ultimately, the answer. Modern computational method: Each hour is divided into 12 segments of 5 minutes each, cycling through all 12 Rasis (Aries to Pisces). Every hour starts fresh from Aries (0 mins) and ends at Pisces (55–60 mins).

FORMULA — Arudham (5-Minute Rule)
minutes_past_hour = query_local_time.minute
arudham_rasi_idx = minutes_past_hour // 5 # 0 to 11
arudham_deg_in_rasi = (minutes_past_hour % 5) * 6.0 # 0–30° within rasi
arudham_total_deg = arudham_rasi_idx * 30.0 + arudham_deg_in_rasi
Python — Arudham Calculation
def calculate_arudham(dt_local: datetime) -> dict:
    """
    Arudham: every 5 minutes of the hour = 1 Rasi (Aries → Pisces).
    Cycles every 60 minutes regardless of sunrise/sunset.
    """
    minutes_past_hour  = dt_local.minute       # 0 to 59
    seconds_past_min   = dt_local.second       # 0 to 59

    # Total seconds past the hour
    total_seconds = minutes_past_hour * 60 + seconds_past_min

    # Each 5-minute block = 300 seconds = 1 Rasi (30°)
    arudham_rasi_idx    = total_seconds // 300       # 0 to 11
    seconds_in_block    = total_seconds % 300        # 0 to 299
    # Each second within the 300s block = 30°/300 = 0.1° of Rasi
    deg_in_rasi         = seconds_in_block * (30.0 / 300.0)

    arudham_total_deg   = (arudham_rasi_idx * 30.0 + deg_in_rasi) % 360.0

    return degree_to_rasi_info(arudham_total_deg)

Kavappu (கவப்பு) — Shadow / Obstacle Point

The overlay that reveals hidden influences and delays
📖 What is Kavappu?

Kavappu (also called Kavippu) is a derived sensitive point in the Jamakkol chart. It indicates hidden obstacles, blockages, or shadow influences on a particular house. It is computed by counting the Rasi distance from Arudham to the active Soorya Veedi (Sun's Path) Rasi, then applying that same distance from the Udhayam.

FORMULA — Kavappu (Soorya Veedi)
# Sun transit determines Soorya Veedi Rasi (0=Aries, 1=Taurus, 2=Gemini)
# Uses 0-indexed Rasis (0 to 11)
kavappu_rasi = (udhayam_rasi + veedi_rasi - arudham_rasi) % 12
Python — Kavappu Calculation
def get_soorya_veedi(sun_rasi: int) -> int:
    if sun_rasi in [1, 2, 3, 4]:
        return 0  # Mesha (Aries)
    elif sun_rasi in [0, 5, 6, 11]:
        return 1  # Vrishabha (Taurus)
    else:
        return 2  # Mithuna (Gemini)

def calculate_kavappu(
    udhayam_rasi: int,
    arudham_rasi: int,
    arudham_deg_in_rasi: float,
    sun_rasi:     int
) -> dict:
    """
    Calculate Kavappu (the shadow/obstacle point) using 0-indexed Rasis.
    """
    veedi_rasi = get_soorya_veedi(sun_rasi)
    kavappu_rasi = (udhayam_rasi + veedi_rasi - arudham_rasi) % 12
    kavappu_deg_in_rasi = 30.0 - arudham_deg_in_rasi - (1.0 / 3600.0)
    kavappu_deg  = kavappu_rasi * 30.0 + kavappu_deg_in_rasi

    return {
        "kavappu_rasi_index" : kavappu_rasi,
        "kavappu_rasi_en"    : RASI_NAMES[kavappu_rasi],
        "kavappu_rasi_ta"    : TAMIL_RASI_NAMES[kavappu_rasi],
        "degree"             : kavappu_deg,
        "is_retrograde"      : True
    }
🔍
Interpretation Note The house lord of the Kavappu Rasi, and any planets placed in or aspecting the Kavappu Rasi, reveal the nature of the obstacle blocking the querent's desire.

Jamam & Jamam Planets (ஜாம கிரகங்கள்)

The 8 symbolic time-period planets of Jamakkol
📖 What is a Jamam?

A Jamam (ஜாமம்) is 1/8th of the daylight period (Day Jamam) or 1/8th of the night period (Night Jamam). Approximately 90 minutes each, but varies by season and latitude. There are 8 Day Jamams and 8 Night Jamams = 16 Jamams per day.

The 8 Jamam Planets

# Jamam planet order (fixed cycle of 8)
JAMAM_PLANETS = ["Sun", "Mars", "Jupiter", "Mercury",
                  "Venus", "Saturn", "Rahu", "Ketu"]

# Day Jamam 1 starting planet by weekday (Sun=0...Sat=6)
DAY_JAMAM_START = {
    0: "Sun",     # Sunday
    1: "Venus",   # Monday (Moon-day; Venus used for 8-planet cycle)
    2: "Mars",    # Tuesday
    3: "Mercury", # Wednesday
    4: "Jupiter", # Thursday
    5: "Venus",   # Friday
    6: "Saturn",  # Saturday
}

def get_jamam_info(jd_query, jd_sunrise, jd_sunset,
                   jd_prev_sunset, jd_next_sunrise,
                   dt_local: datetime, sun_rasi: int) -> dict:
    is_day = jd_sunrise <= jd_query < jd_sunset

    if is_day:
        span_start, span_end = jd_sunrise, jd_sunset
    elif jd_query < jd_sunrise:
        span_start, span_end = jd_prev_sunset, jd_sunrise
    else:
        span_start, span_end = jd_sunset, jd_next_sunrise

    # Duration of each Jamam in days
    jamam_dur_days  = (span_end - span_start) / 8.0
    jamam_dur_mins  = jamam_dur_days * 1440.0

    # Elapsed time from span start
    elapsed_days    = jd_query - span_start
    elapsed_mins    = elapsed_days * 1440.0

    # Current Jamam number (1 to 8)
    jamam_num = int(elapsed_mins // jamam_dur_mins) + 1
    jamam_num = max(1, min(8, jamam_num))
    mins_in_jamam = elapsed_mins % jamam_dur_mins

    # Jamam lord: rotate through JAMAM_PLANETS starting from weekday's start planet
    # Python weekday(): 0=Mon...6=Sun → Jamakkol: 0=Sun...6=Sat
    py_weekday  = dt_local.weekday()
    jk_weekday  = (py_weekday + 1) % 7  # Shift to Sun=0
    start_p     = DAY_JAMAM_START[jk_weekday]
    start_idx   = JAMAM_PLANETS.index(start_p)
    lord_idx    = (start_idx + jamam_num - 1) % 8
    jamam_lord  = JAMAM_PLANETS[lord_idx]

    # Jamam planets positioned clockwise from Sun's Rasi
    jamam_positions = {}
    for i, planet in enumerate(JAMAM_PLANETS):
        p_rasi_idx = (sun_rasi + i) % 12
        jamam_positions[planet] = {
            "rasi_index"  : p_rasi_idx,
            "rasi_name_en": RASI_NAMES[p_rasi_idx],
            "rasi_name_ta": TAMIL_RASI_NAMES[p_rasi_idx],
        }

    return {
        "is_day_jamam"     : is_day,
        "jamam_number"     : jamam_num,
        "jamam_lord"       : jamam_lord,
        "jamam_duration_m" : round(jamam_dur_mins, 2),
        "elapsed_in_jamam_m": round(mins_in_jamam, 2),
        "planets"          : jamam_positions,
    }

    "Moon"    : swe.MOON,

    "Mercury" : swe.MERCURY,
    "Jupiter" : swe.JUPITER,

def get_all_planets(jd_ut: float) -> dict:
    """Get sidereal positions of all 9 planets."""
    flags   = swe.FLG_SWIEPH | swe.FLG_SIDEREAL | swe.FLG_SPEED
    planets = {}

    for name, pid in PLANET_IDS.items():
        res, _ = swe.calc_ut(jd_ut, pid, flags)
        lon  = res[0] % 360.0
        lat  = res[1]
        dist = res[2]
        spd  = res[3]

        rasi_idx    = int(lon // 30)
        deg_in_rasi = lon % 30
        nak_idx     = int(lon // (360 / 27))
        pada        = int((lon % (360/27)) // (360/108)) + 1

        planets[name] = {
            "total_degree"    : round(lon, 6),
            "rasi_index"      : rasi_idx,
            "rasi_name_en"    : RASI_NAMES[rasi_idx],
            "rasi_name_ta"    : TAMIL_RASI_NAMES[rasi_idx],
            "degree_in_rasi"  : round(deg_in_rasi, 4),
            "nakshatra"       : NAKSHATRAS[nak_idx],
            "nakshatra_pada"  : pada,
            "is_retrograde"   : spd < 0,
            "daily_speed_deg" : round(spd, 6),
            "latitude"        : round(lat, 4),
            "distance_au"     : round(dist, 6),
        }

    # Ketu = Rahu + 180° (always true node opposite)
    rahu_lon  = planets["Rahu"]["total_degree"]
    ketu_lon  = (rahu_lon + 180.0) % 360.0
    ketu_rasi = int(ketu_lon // 30)
    ketu_nak  = int(ketu_lon // (360/27))

    planets["Ketu"] = {
        "total_degree"   : round(ketu_lon, 6),
        "rasi_index"     : ketu_rasi,
        "rasi_name_en"   : RASI_NAMES[ketu_rasi],
        "rasi_name_ta"   : TAMIL_RASI_NAMES[ketu_rasi],
        "degree_in_rasi" : round(ketu_lon % 30, 4),
        "nakshatra"      : NAKSHATRAS[ketu_nak],
        "is_retrograde"  : True,  # Ketu is always retrograde
        "daily_speed_deg": round(-planets["Rahu"]["daily_speed_deg"], 6),
    }

    return planets

Mandi & Gulika (Upagrahas)

Shadow sub-planets — not in the ephemeris, computed manually
📖 What are Mandi & Gulika?

Mandi and Gulika are Upagrahas (sub-planets) — mathematically derived sensitive points, not real celestial bodies. They are extremely important in Tamil Jamakkol and Kerala astrology for malefic analysis. They are computed by finding Saturn's Kala (time allocation) within the day/night and calculating the Ascendant at that specific moment.

Mandi Calculation — Day Chart

📌
Kala = 1/8 of Daylight (or Night) Period Mandi rises when the Kala allocated to Saturn begins. Gulika's rising is 1 Kala (1/8th period) before Mandi's start.

# Saturn Kala index (0-indexed) for Day chart, per weekday (Sun=0...Sat=6)
MANDI_DAY_KALA   = [5, 4, 7, 3, 2, 1, 6]   # (0-indexed: 0=Kala1)
MANDI_NIGHT_KALA = [0, 1, 4, 2, 3, 6, 7]

def calculate_mandi_gulika(
    jd_sunrise, jd_sunset, jd_prev_sunset, jd_next_sunrise,
    dt_local: datetime, lat: float, lon: float
) -> dict:
    """
    Compute Mandi (Saturn's Upagraha) and Gulika Lagnas.
    Method: Find start time of Saturn's Kala, compute Ascendant at that moment.
    """
    py_weekday  = dt_local.weekday()              # 0=Mon...6=Sun
    jk_weekday  = (py_weekday + 1) % 7           # Convert to 0=Sun

    # ── Day Mandi ──────────────────────────────────────────────
    day_kala_dur    = (jd_sunset - jd_sunrise) / 8.0
    mandi_day_kala  = MANDI_DAY_KALA[jk_weekday]
    jd_mandi_day    = jd_sunrise + mandi_day_kala * day_kala_dur
    jd_gulika_day   = jd_mandi_day - day_kala_dur  # Gulika = 1 Kala before Mandi

    # ── Night Mandi ────────────────────────────────────────────
    night_kala_dur  = (jd_next_sunrise - jd_sunset) / 8.0
    mandi_night_kala= MANDI_NIGHT_KALA[jk_weekday]
    jd_mandi_night  = jd_sunset + mandi_night_kala * night_kala_dur

    # ── Compute Ascendant (tropical) at each Mandi JD ──────────
    def get_sidereal_asc(jd):
        cusps, ascmc = swe.houses(jd, lat, lon, b'P')
        ayanamsa     = swe.get_ayanamsa_ut(jd)
        return (ascmc[0] - ayanamsa) % 360.0

    mandi_day_lon   = get_sidereal_asc(jd_mandi_day)
    gulika_day_lon  = get_sidereal_asc(jd_gulika_day)
    mandi_night_lon = get_sidereal_asc(jd_mandi_night)

    return {
        "mandi_day"   : degree_to_rasi_info(mandi_day_lon),
        "gulika_day"  : degree_to_rasi_info(gulika_day_lon),
        "mandi_night" : degree_to_rasi_info(mandi_night_lon),
    }

Panchangam Elements

Thithi, Nakshatra, Yogam, Karanam, Vaaram

All 5 Panchangam elements are derived from Sun and Moon longitudes. No separate library needed.

CORE FORMULAS
moon_sun_diff = (moon_lon - sun_lon) % 360.0

THITHI → moon_sun_diff / 12° → index 0–29 → 30 Thithis
YOGAM → (moon_lon + sun_lon) % 360 / (360/27) → 27 Yogams
KARANAM → (moon_sun_diff % 12) / 6° → 11 Karanams (cyclic)
NAKSHATRA → moon_lon / (360/27) → 27 Nakshatras

    "Shakuni", "Chatushpada", "Naga", "Kimstughna",  # Fixed 4
]

def calculate_panchangam(jd_ut: float, dt_local: datetime) -> dict:
    flags    = swe.FLG_SWIEPH | swe.FLG_SIDEREAL
    sun_res, _  = swe.calc_ut(jd_ut, swe.SUN,  flags)
    moon_res, _ = swe.calc_ut(jd_ut, swe.MOON, flags)

    sun_lon  = sun_res[0]  % 360.0
    moon_lon = moon_res[0] % 360.0
    diff     = (moon_lon - sun_lon) % 360.0

    # ── Thithi ──────────────────────────────────────────────────
    thithi_idx    = int(diff / 12.0)         # 0 to 29
    thithi_num    = (thithi_idx % 15) + 1    # 1–15
    paksha        = "Shukla" if thithi_idx < 15 else "Krishna"

    # ── Nakshatra (Moon) ────────────────────────────────────────
    NAK_SIZE      = 360.0 / 27.0
    nak_idx       = int(moon_lon / NAK_SIZE)
    pada          = int((moon_lon % NAK_SIZE) / (NAK_SIZE / 4)) + 1

    # ── Yogam ───────────────────────────────────────────────────
    yogam_idx     = int((sun_lon + moon_lon) % 360.0 / (360.0/27))

    # ── Karanam ─────────────────────────────────────────────────
    # First Karanam of Thithi 1 starts: Kimstughna (fixed)
    # Then 7 Cara Karanams repeat; last 4 are fixed
    karana_num    = int(diff / 6.0)           # 0 to 59
    if karana_num == 0:
        karana_name = "Kimstughna"             # Fixed first
    elif karana_num >= 57:
        fixed = ["Shakuni", "Chatushpada", "Naga"]
        karana_name = fixed[karana_num - 57]  # Fixed last 3
    else:
        karana_name = KARANAMS[(karana_num - 1) % 7]

    # ── Vaaram ──────────────────────────────────────────────────
    VAARAMS = ["Somavar (Mon)", "Sevvai (Tue)", "Budhan (Wed)",
               "Viyazhan (Thu)", "Velli (Fri)", "Sani (Sat)", "Nyaniru (Sun)"]
    vaaram = VAARAMS[dt_local.weekday()]

    return {
        "vaaram"    : vaaram,
        "thithi"    : {"number": thithi_num, "paksha": paksha},
        "nakshatra" : {"name": NAKSHATRAS[nak_idx], "pada": pada},
        "yogam"     : YOGAMS[yogam_idx],
        "karanam"   : karana_name,
    }

def get_day_boundaries(
    jd_query: float,
    lat: float, lon: float,
    altitude: float = 0
) -> dict:
    """
    Get all time boundaries needed for Jamakkol:
    - Today's sunrise, sunset
    - Yesterday's sunset (for pre-sunrise night queries)
    - Tomorrow's sunrise (for post-sunset night queries)
    """
    def rise_set(jd_start):
        r, _ = swe.rise_trans(jd_start, swe.SUN,
                               swe.CALC_RISE, lon, lat, altitude, 0, 0)
        s, _ = swe.rise_trans(jd_start, swe.SUN,
                               swe.CALC_SET,  lon, lat, altitude, 0, 0)
        return r[0], s[0]

    # Use midnight UTC as anchor (search forward from midnight)
    jd_midnight  = int(jd_query) - 0.5  # noon → midnight approximation

    today_sr, today_ss   = rise_set(jd_midnight)
    prev_sr,  prev_ss    = rise_set(jd_midnight - 1.0)  # Yesterday
    next_sr,  next_ss    = rise_set(jd_midnight + 1.0)  # Tomorrow

    return {
        "today_sunrise"   : today_sr,
        "today_sunset"    : today_ss,
        "prev_sunset"     : prev_ss,
        "next_sunrise"    : next_sr,
        "day_duration_h"  : (today_ss  - today_sr) * 24,
        "night_duration_h": (next_sr   - today_ss) * 24,
    }

from datetime import datetime, timezone, timedelta

def jd_to_ist(jd: float, tz_offset: float = 5.5) -> str:
    """Convert Julian Day to IST string."""
    y, m, d, h = swe.revjul(jd, swe.GREG_CAL)
    dt_utc = datetime(int(y), int(m), int(d),
                       int(h), int((h%1)*60), int(((h%1)*60)%1*60))
    dt_ist = dt_utc + timedelta(hours=tz_offset)
    return dt_ist.strftime("%H:%M:%S IST")

jamakkol_engine.py
High-accuracy Jamakkol Prasanam calculation engine.

from datetime import datetime, timedelta

def dri(deg: float) -> dict:
    """Degree to Rasi Info — core helper used everywhere."""
    deg  = deg % 360.0
    ri   = int(deg // 30)
    ni   = int(deg // (360/27))
    pada = int((deg % (360/27)) // (360/108)) + 1
    return {
        "deg": round(deg,4), "rasi": ri,
        "rasi_en": RASI_NAMES_EN[ri], "rasi_ta": RASI_NAMES_TA[ri],
        "deg_in_rasi": round(deg%30,4),
        "nak": NAKSHATRAS[ni], "pada": pada
    }

def jd_from_dt(dt: datetime) -> float:
    return swe.julday(dt.year,dt.month,dt.day,
        dt.hour+dt.minute/60+dt.second/3600, swe.GREG_CAL)

def rise_set(jd_start,lat,lon,alt=0):
    r,_=swe.rise_trans(jd_start,swe.SUN,swe.CALC_RISE,lon,lat,alt,0,0)
    s,_=swe.rise_trans(jd_start,swe.SUN,swe.CALC_SET, lon,lat,alt,0,0)
    return r[0],s[0]

def compute(dt_local:datetime, lat:float, lon:float,
             tz_h:float=5.5, alt:float=0) -> dict:
    """
    Master function. Returns complete Jamakkol chart.
    dt_local : local datetime of query
    lat/lon  : astrologer's location (degrees)
    tz_h     : timezone offset in hours (IST = 5.5)
    alt      : elevation in meters
    """
    # UTC conversion
    dt_utc    = dt_local - timedelta(hours=tz_h)
    jd        = jd_from_dt(dt_utc)
    ayanamsa  = swe.get_ayanamsa_ut(jd)

    # Day boundaries
    midnight   = int(jd) - 0.5
    sr, ss     = rise_set(midnight,   lat, lon, alt)
    psr, pss   = rise_set(midnight-1, lat, lon, alt)
    nsr, nss   = rise_set(midnight+1, lat, lon, alt)

    # Planets
    flags  = swe.FLG_SWIEPH | swe.FLG_SIDEREAL | swe.FLG_SPEED
    pmap   = {"Sun":swe.SUN,"Moon":swe.MOON,"Mars":swe.MARS,
              "Mercury":swe.MERCURY,"Jupiter":swe.JUPITER,
              "Venus":swe.VENUS,"Saturn":swe.SATURN,
              "Rahu":swe.TRUE_NODE}
    nps    = {}
    for nm,pid in pmap.items():
        r,_ = swe.calc_ut(jd,pid,flags)
        info = dri(r[0])
        info["retro"] = r[3] < 0
        info["speed"] = round(r[3],6)
        nps[nm] = info
    ketu_lon      = (nps["Rahu"]["deg"]+180) % 360
    nps["Ketu"]   = dri(ketu_lon)
    nps["Ketu"]["retro"] = True

    # Sun rasi (for Udhayam base and Jamam planet placement)
    sun_rasi = nps["Sun"]["rasi"]

    # Udhayam
    is_day  = sr <= jd < ss
    span_s  = sr  if is_day else (pss if jd<sr else ss)
    span_e  = ss  if is_day else (sr  if jd<sr else nsr)
    frac   = (jd-span_s) / (span_e-span_s)
    udh    = dri(sun_rasi*30 + frac*360)

    # Arudham
    total_sec   = dt_local.minute*60 + dt_local.second
    ard_rasi    = total_sec // 300
    ard_deg     = ard_rasi*30 + (total_sec%300)*(30/300)
    ard         = dri(ard_deg)

    # Kavappu (Soorya Veedi)
    veedi_rasi   = 0 if sun_rasi in [1, 2, 3, 4] else (1 if sun_rasi in [0, 5, 6, 11] else 2)
    kav_rasi     = (udh["rasi"] + veedi_rasi - ard_rasi) % 12
    kav_deg_in   = 30.0 - (ard_deg % 30.0) - (1.0 / 3600.0)
    kav          = dri(kav_rasi * 30.0 + kav_deg_in)

    # Jamam
    jkw  = (dt_local.weekday()+1)%7
    jdur = (span_e-span_s)/8
    jnum = max(1,min(8,int((jd-span_s)/jdur)+1))
    jlrd = JAMAM_PLANETS[(JAMAM_PLANETS.index(DAY_JAMAM_START[jkw])+jnum-1)%8]
    jpos = {p: dri((sun_rasi+i)%12*30) for i,p in enumerate(JAMAM_PLANETS)}

    # Mandi & Gulika
    def sasc(jd2):
        c,a=swe.houses(jd2,lat,lon,b'P')
        return (a[0]-swe.get_ayanamsa_ut(jd2))%360
    mkd  = MANDI_DAY_KALA[jkw]
    jm_d = sr + mkd*(ss-sr)/8
    jg_d = jm_d - (ss-sr)/8

    # Panchangam
    sun_l  = nps["Sun"]["deg"]
    mon_l  = nps["Moon"]["deg"]
    diff   = (mon_l-sun_l)%360
    thithi_idx = int(diff/12)

    return {
        "query"    : dt_local.isoformat(),
        "ayanamsa" : round(ayanamsa,4),
        "udhayam"  : udh,
        "arudham"  : ard,
        "kavappu"  : kav,
        "jamam"    : {
            "is_day"      : is_day,
            "number"      : jnum,
            "lord"        : jlrd,
            "duration_m"  : round(jdur*1440,2),
            "planets"     : jpos,
        },
        "nitya_planets" : nps,
        "upagrahas"     : {
            "mandi"  : dri(sasc(jm_d)),
            "gulika" : dri(sasc(jg_d)),
        },
        "panchangam"    : {
            "thithi_num"  : (thithi_idx%15)+1,
            "paksha"      : "Shukla" if thithi_idx<15 else "Krishna",
            "nakshatra"   : nps["Moon"]["nak"],
            "yogam_idx"   : int((sun_l+mon_l)%360/(360/27)),
        },
        "sunrise_ist" : jd_to_ist(sr, tz_h),
        "sunset_ist"  : jd_to_ist(ss, tz_h),
    }

def jd_to_ist(jd, tz_h=5.5):
    y,m,d,h=swe.revjul(jd,swe.GREG_CAL)
    h += tz_h
    hr = int(h%24); mn=int((h%1)*60); sc=int(((h%1)*60%1)*60)
    return f"{hr:02d}:{mn:02d}:{sc:02d} IST"

Accuracy Tips & Troubleshooting

Achieving parity with jamakkol.com
Issue / CheckCorrect Approach
Wrong AyanamsaAlways use swe.SIDM_LAHIRI. jamakkol.com uses Lahiri (Chitra Paksha).
Wrong timezoneConvert all inputs to UTC before passing to swe. IST = UTC+5:30 (subtract 5.5h).
Sunrise off by minutesPass exact latitude, longitude, and elevation (alt). Even 10m altitude changes sunrise by seconds.
Retrograde discrepancyUse swe.TRUE_NODE for Rahu (not MEAN_NODE). jamakkol.com uses True Node.
Udhayam is differentEnsure you start from Sun's Rasi boundary (not the Sun's exact degree). Start degree = sun_rasi_index × 30.
Arudham off by 1 RasiCheck if implementation uses inclusive or exclusive counting. Apply to full seconds (not just minutes).
Kavappu variesTwo methods exist: counting to Sun's Rasi from Arudham, or to Sun's Navamsa. Match jamakkol.com's output to verify which.
Mandi wrongDouble-check Kala index (0-based vs 1-based) in your lookup table. Mandi = start of Saturn's Kala, not midpoint.
